# 직소 언어 퍼즐 모음

졸업프로젝트에서 제작한 HTML 퍼즐 시험본과 관련 소스·설계·검토 자료입니다. 본편의 확정 콘텐츠가 아닌 실험용 표본입니다.

## 실행

저장소 전체를 내려받고 **index.html**을 Chrome 또는 Edge로 열거나, Windows에서 **실행.bat**을 더블클릭하세요. 인터넷·서버·설치 없이 실행됩니다. HTML 하나만 내려받으면 모음 페이지의 다른 퍼즐 링크는 열리지 않으므로 폴더 전체를 받아 주세요.

- 일대일 두 사건: 높은 선착장의 책 / 돌아온 빈 운반함
- 같은 요소를 재조합한 6레벨
- 새로운 판단을 비교하는 변주 6개
- 소통 변주 12퍼즐
- 개별 퍼즐 13–22: 보라색 연결 등

진행은 브라우저에 저장됩니다. 다른 PC·브라우저로 자동 동기화되지 않습니다. 검토·분석 자료에는 풀이가 포함됩니다.

## SourceTree로 받기

1. SourceTree에서 **복제(Clone)** 선택.
2. 소스 경로에 `https://github.com/cj3075201-sudo/puzzle.git` 입력.
3. 빈 대상 폴더를 선택하고 복제.
4. 복제된 폴더의 `index.html` 실행. 이후 변경은 Pull로 받습니다.

이 PC에서는 이미 Git 저장소로 만든 `C:\Users\cj307\Desktop\puzzle`을 **기존 로컬 저장소 추가**로 등록하면 됩니다.

공개 저장소이므로 누구나 내려받을 수 있습니다. 원본 저장소에 Push하려면 소유자가 부여한 쓰기 권한이 필요합니다. 권한 없이 제안하려면 Fork 후 Pull Request를 사용하세요.

## 소스 수정

`기록/직소우_바리에이션_검토01/` 아래에 퍼즐별 JavaScript·CSS·HTML 템플릿·생성기·설계·기존 검토 결과를 보존했습니다. `index.html`은 실행 모음입니다. 옛 비교 실험과 기록도 포함되어 있으며, 모음에 연결된 항목부터 실행하는 것을 권장합니다.

플레이에는 개발 도구가 필요 없습니다. 소스를 변경해 HTML을 재생성할 때는 Python 3와 의존성을 설치합니다.

```sh
python -m pip install -r requirements.txt
python -X utf8 "기록/직소우_바리에이션_검토01/퍼즐22_보라색연결/만들기.py"
```

운영체제에 따라 `python` 대신 `python3`를 사용하세요. 생성기는 자신의 파일 위치를 기준으로 동작합니다. `플레이.html`에 소스가 내장되므로 JS/CSS 수정 후 해당 폴더의 `만들기.py`를 실행해야 플레이에 반영됩니다. 일부 과거 검토 자동화에는 당시 PC 경로가 남아 있어 그대로 재실행할 수 없으며, 동봉 결과는 당시 기록입니다.

`기획서/source/assets/Pretendard-Regular.ttf`는 빌드용 글꼴입니다. 라이선스는 같은 폴더 `OFL.txt`에 있습니다. 게임 소스의 오픈소스 라이선스는 별도로 지정하지 않았습니다.
