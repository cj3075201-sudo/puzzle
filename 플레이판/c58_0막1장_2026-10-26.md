# Once Under a Time — 0막~1장 플레이판 c58 (2026-10-26)

김승겸 작업본. 0막(튜토리얼)부터 1장 끝까지 이어서 플레이되는 시제품 판.

## 실행
1. `OnceUnderATime_c58_0막1장_2026-10-26.zip` 받아서 압축 풀기
2. `OnceUnderATime_c58` 폴더 안에서
   - `전체판_0막부터.bat` — 0막부터 1장 끝까지
   - `10분판.bat` — 1장 앞부분 10분짜리
3. 소리는 게임 안 Esc → 설정에서 조절

## 이 판의 상태
- 장소는 그레이박스, 인물·소품은 임시 모델 (정식 아트는 시작 단계)
- 퍼즐 판은 재설계 전 판 (긴 문장·갈래·주체 표시 재설계는 반영 전)
- 스토리 흐름은 다시 정하는 중
- 고친 것: 0막 승강 바구니 탑승, "처음부터" 다시 시작 시 장소 바뀜, 앉은돌 길목 진행 막힘, 클릭 표시 위치, 파랑으로 시작하는 말이 통하던 판정
