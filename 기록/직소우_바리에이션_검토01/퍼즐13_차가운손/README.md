## 플레이

목표: 손이 차가운 주민에게 빌린 열쇠를 돌려준다.

1. 월드의 두 주민을 클릭해 직소우 발화를 읽는다. 휠 클릭은 대상 강조다.
2. 모형을 선택해 빈 칸에 놓고, 글자를 골라 넣는다. 모형과 글자는 따로 선택하며 반복 사용한다.
3. 조각을 끌어 실제 홈과 돌출을 맞춘 뒤 말한다. 선택 뒤 빈 칸 클릭/방향키로도 이동한다.
4. 실패 후 조립은 유지된다. 글자 교체·조각 삭제·되돌리기로 수정한다.

발화 재열람, 대화 접기, 소리 끄기, 처음부터, 새로고침 복원을 제공한다. Delete는 선택 조각 삭제, Ctrl+Z는 되돌리기다. 진행은 해당 브라우저의 로컬 저장소에 보관한다.

## 설계표 — D01 / D03 / G03 / G04 관련 표본

| 항목 | 구현한 내용 |
|---|---|
| 시작 | 플레이어가 열쇠를 가진다. 주민 둘은 집의 안쪽과 바깥쪽에서 같은 문턱을 향한다. 목표는 기억한 반환 약속으로 제시한다. |
| 보유 지식 | 기본 단어 뜻·색·원형 접합·두 갈래 주체를 이미 배운 시점. 한국어는 알려진 뜻을 표시한다. |
| 단서 | 집 안 주민: 손에서 아프다/차갑다로 분기. 집 밖 주민: 손→아프다, 발→차갑다 두 발화. 외형·색으로 증상을 드러내지 않는다. |
| 판단 | 차갑다가 어느 부위와 연결됐는지 읽고, 해당 주민을 위치 사슬로 지칭한다. 이 장면에서는 집→안/밖→주민과 안/밖→주민을 모두 수용한다. 이어 내가 주는 주체가 되도록 조립한다. |
| 입력 | 6×4 자유 격자, 제시 모형 8종, 글자 7개, 각 재료 반복 사용. 회전 없음. 정답 좌표나 클릭 순서를 강제하지 않는다. |
| 수신자 | 두 주민이 함께 듣는다. 마지막 클릭·마지막 열람 발화로 주민을 자동 특정하지 않는다. |
| 판정 | 접합 방향 그래프→노랑 사슬→주다의 표시형 주체/일반 입력/출력 물건→실제 소유→대상 반응. |
| 정상 실행 | 내가 집 안 주민에게 열쇠를 건네면 열쇠가 그 주민에게 이동하고 완료. 주민이 감사하며 문을 더 열어 초대한다. |
| 다른 상대 | 바깥 주민에게 전달하면 잠깐 내민 열쇠가 돌아온다. 감점·초기화 없이 수정 가능. |
| 반대 주체 | 주민에게 열쇠가 없으므로 빈손 반응. 현재 열쇠 소유는 플레이어로 유지. |
| 부족한 지칭 | 주민만 말하면 둘이 반응하며 대상을 더 특정해야 한다. |
| 미완성 | 빈 글자/떨어진 조각/맞지 않는 접합은 해당 수정 안내. 남는 정답 외 조각을 무시하지 않는다. |
| 종료 | 열쇠 소유=안쪽 주민, 반환 완료. 재제출로 중복 실행되지 않는다. |
| 복구 | 오답 시 조각 유지, 한 단계 되돌리기, 선택 삭제, 재열람, 조립·열람·완료 상태 새로고침 복원, 연출 중 처음부터 취소. |

정답을 실제로 입력한 경우 양쪽 발화 열람을 강제하지 않는다. 두 상대를 순서대로 시도해 성공하는 경로도 허용한다. 로컬 시도 기록에 입력·판정·당시 열람 여부를 남겨 읽기 후 성공과 피드백 후 수정을 구별할 수 있게 했다.

## 제작 판단

- 단어 해독을 다시 가르치는 퍼즐보다, 배운 문장의 연결을 읽고 직접 소통하는 첫 적용 퍼즐로 추천한다.
- 기존 비교12의 상태 분기/주체 선택과 비교11의 위치 지칭을 하나의 행동으로 연결했다.
- 열쇠 반환이 목표다. 문 열림은 감사·초대 연출이며, 이 열쇠로만 탈출 문을 여는 설정을 추가하지 않았다.
- 기존 다각형 생성 함수와 Pretendard 글꼴을 재사용했다. 배경·크리처·소유 이동은 SVG로 표현했고, 짧은 합성음을 연결했다.
- 새 Unity 본편은 착수하지 않았다. 이 HTML은 현재 승인된 단일 퍼즐 체험 표본이다.

## 사용자 플레이 수정 — 안→주민 생략 표현

2026-09-29 사용자가 안→주민 / 나(두 갈래 주체)→주다→열쇠의 실제 5조각 스크린샷을 보내며 거절 이유를 질문했다. 물리 접합과 역할은 올바랐으나, 장면 지칭 resolver가 집|안|주민만 등록해 안|주민을 거절하고 있었다. AI가 유효한 짧은 표현을 빠뜨린 판정 오류다.

기준 집이 하나인 현재 장면의 문맥을 반영해 안→주민/밖→주민을 기존 세 조각 지칭과 동등하게 수용한다. actor와 recipient 양쪽에 같은 해석을 적용하며 주체·물건·소유 검사와 주민 단독 모호함은 유지한다. 고정 좌표 정답 비교가 아니라 실제 접합 그래프와 장면별 지칭 규칙을 쓰는 판정이다.

사용자 배치의 회귀 검사는 수정 전 unsupported_meaning으로 실패했고 수정 후 complete로 통과했다. 전체 판정 30개, 실제 Edge 5조각 UI 제출·소유 이동·완료 표시 5개 통과. [수정 검증](짧은표현_수정검증.json). 입력·저장 형식은 유지하여 기존 조립을 새로고침 후 그대로 재제출할 수 있다.
