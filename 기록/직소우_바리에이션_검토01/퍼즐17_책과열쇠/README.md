# 퍼즐17 — 책과 열쇠

2026-09-29 사용자 “만들어봐” 승인 제작. [플레이](플레이.html). 서버/포트 없이 파일 실행. 퍼즐13~16 보존.

## 플레이와 판정

초기 안쪽 창고지기는 열쇠, 바깥 심부름꾼은 책을 소지한다. 책을 맡아야 열쇠를 빌려준다는 단서를 화면에 표시한다. 최초 책이 창고지기에게 도착하면 창고지기는 책을 들고 바깥 반납대로, 심부름꾼은 안쪽 수령대로 자동 이동한다. 현재 위치와 소지품이 바뀐 다음 발화를 판정한다.

주는 주체는 두 갈래 연결, 받는 대상은 원형 입력, 물건은 출력. 양쪽 지칭은 전달 전 상태에서 해결한다. 책을 가진 주민은 교대 뒤 창고지기이므로 이 표현을 심부름꾼으로 계속 읽지 않는다. 나를 거친 전달도 허용한다. 책을 회수했다 다시 맡겨도 교대는 첫 담보 한 번만 발생한다.

완료: 책이 창고지기에게 있고 열쇠가 심부름꾼에게 있다. 단순히 창고지기를 클릭했다고 받는 대상으로 결정하지 않는다. 이번 화면은 가지다/주다만 제공하며 가다 단어는 제공하지 않는다. 두 주민은 대여 절차에 따라 이동한다. 노랑 사슬3·회전없음·모형글자분리·재사용 유지.

## 설계 검토 정정

사전 검토의 “고정된 위치지칭을 반복할 수 없다”는 판단은 틀렸다. 처음에는 밖 B→안 A 책, 교대 뒤에는 밖 A→안 B 열쇠이므로 **동일 위치 기반 주다 조립에서 물건만 바꾸는 유효한 풀이가 있다.** 이 풀이를 거절하지 않고 브라우저 검사로 성공을 확인했다. 따라서 이번 구현 자체를 16보다 높은 난도 증거로 기록하지 않는다. 다음 난도 판단에 이 짧은 풀이를 반영한다. 물건 조건으로 특정한 문장의 의미 변화는 실제 구현된다.
