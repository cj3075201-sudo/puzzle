# 대화 표본20 — 누구의 손

2026-09-29 사용자 “일단 만들어보자. 이게 큰차이가 있는지는 모르겠지만” 승인 제작. [플레이](플레이.html). 서버/포트 없이 파일 실행. 기존 퍼즐13~19 보존.

## 장면과 대화

진료소 환자가 내민 손에 다가가면 접촉 직전 움찔하며 손을 거둔다. 손→차갑다라고 말한다. 실제 불편은 플레이어 손의 낮은 온도다. 주민→손→차갑다로 이해를 확인하면 환자는 고개를 젓고 플레이어 손을 가리킨다. 나→손→차갑다는 끄덕이며 김이 나는 수건 쪽을 보게 한다. 환자의 자기 손이 따뜻하다는 표현에는 자기 손바닥을 펼쳐 보인 뒤 플레이어 손을 가리켜 차이를 설명한다.

플레이어는 실제 수건을 클릭해 손을 데우고 환자에게 다시 접근한다. 따뜻한 손이면 환자가 손을 거두지 않고 손을 얹어 진찰을 받아들인다. 말만 맞히면 자동으로 손이 데워지거나 완료되지 않는다. 반대로 처음부터 알아차려 수건을 사용하고 접근해도 성공한다. 잘못된 답을 먼저 제출하거나 정해진 문장을 제출하는 것을 강제하지 않는다.

이 표본의 새 용례는 상태 진술을 이해 확인으로 받아 상대가 몸짓/발화로 정정하는 대화다. 범용 질문문법이나 실제 의학적 진단 체계를 채택하지 않는다. 한국어 기본 뜻, 노랑 대상/파랑 상태, 실제 직소우 모형과 글자 분리, 회전없음, 노랑사슬3 유지. 나/주민→손→상태 또는 손→상태를 읽으며, 생략된 주인은 확인 반응으로 명확히 한다. 상대 발화의 나는 환자, 내 발화의 나는 플레이어다.

## 반응/입력

환자 클릭=다가가 손을 대려 하기. 수건 클릭=손 데우기. 다시듣기=현재 상황에서 환자의 발화. 내 말은 실제 모형을 놓고 글자를 넣어 조립한다. 조립은 소유자·신체·상태를 실제 접합으로 판정하며 의미없는 연결/빈글자는 구체 오류 표시. 몸짓은 손 거두기, 플레이어 손 가리키기, 자기 손 내보이기, 끄덕임, 손 내밀기. 수건 쪽으로 이동해 손을 데우는 동작과 상태색 변경 포함.

understood는 나의 차가운 손이라는 발화를 확인했을 때만 기록한다. 행동만으로 성공한 경로는 이해를 발화로 확인했다고 기록하지 않는다. 반복 실패로 자동 진행하지 않는다. 데운 뒤 응답도 현재 따뜻한 온도를 반영한다.
