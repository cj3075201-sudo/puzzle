# 보라색 연결 · 퍼즐22

2026-09-29. 사용자 “이것도 좋고, 아예 새로운 색깔을 활용해서도 만들어봐 … 다른 어떤 거든 새로운 거”로 새 기능 제작 승인. [플레이](플레이.html)는 서버 없이 실행되는 독립 HTML이다.

## 새 기능과 두 장면

보라색 ○·△·◇는 아직 이름을 정하지 않은 대상 자리다. 같은 표식은 떨어진 문장에서도 동일한 실제 대상을 가리킨다. 모든 관찰 관계를 동시에 만족하는 값을 찾아 마지막 행동의 상대와 대상을 정한다. 서로 다른 표식은 독립 변수이며, 별도의 부등 제약이 없으므로 같은 실체로 정해질 수도 있다.

- 장면1: 열쇠 보유, 시선, 문의 소리를 함께 만족하는 주민과 문을 찾는다. 같은 이름이 여러 관찰에서 한 대상을 뜻한다는 규칙을 익힌다.
- 장면2: 서로를 보는 두 주민 중 열쇠를 가진 쪽에게 협력을 부탁한다. 두 보다 문장의 시작/끝 표식을 뒤집어 상호 관계를 만든다. 같은 방향의 말만 반복하면 후보가 남는다.
- 노랑: 대상·종류. 파랑: 관계와 행동. 보라: 같은 실체를 공유하는 이름 자리. 기존 파랑에 조건 단어를 추가하는 방식에서, 떨어진 직소 문장들의 동일 대상 연결로 계산 구조를 확장했다.
- 21의 부탁판 글자 이동은 사용하지 않는다. 이번 보라 규칙은 HTML 표본에서 시험하며 본편 채택은 사용자 플레이 반응 뒤 판단한다.

## 입력과 정보

세계 그림의 열쇠·시선 화살표·음표가 관계 데이터와 대응한다. 주민 클릭으로 해당 관찰을 확인할 수 있다. 왼쪽 후보 표시는 현재 조립된 모든 문장을 만족하는 대상을 보여 주며, 하나씩 정답을 입력하는 문자열 검사 방식은 쓰지 않는다.

초기 조립판에는 관찰 세 문장과 부탁 한 문장의 실제 직소 모형이 있고, 보라 조각의 표식만 비어 있다. 조각 선택 후 ○·△·◇를 넣는다. 판 비우기와 모형/글자 팔레트로 모든 조각을 다시 조립할 수도 있다. 노랑/파랑 원래 모형, 회전 금지, 비소모 공급, 열두 조각, 한 표현의 노랑 연속 제한을 유지했다. 보라 모형은 기존 노랑의 직소 외곽/홈을 복제하고 별도 색/어휘로 구별한다.

여러 떨어진 성분을 허용하는 것은 새 보라 연결의 일부다. 각 성분의 물리 접합은 원래 core.js로 검사한 뒤, 같은 보라 표식의 의미 제약을 함께 계산한다. 조각이 서로 닿아 있으면 기존 홈/돌출 충돌 검사가 그대로 적용된다. 세 조각 관계 표현이 이번 표본의 문법 범위다.

## 상태·실패·완료

1. 조립 기하와 각 문장의 대상→관계→대상 구조를 검사한다.
2. 관찰문만으로 가능한 보라 이름 배정을 찾는다.
3. 실행 상대 조합이 여러 개면 되묻고, 관찰이 모순이면 공통 대상이 없다고 알려 준다.
4. 실행 대상이 하나로 정해진 뒤에만 실제 행동 전제를 확인한다. 행동이 가능하다는 이유로 후보를 몰래 좁히지 않는다.
5. 장면1은 열쇠 보유자가 바라보는 소리 나는 문을 열고, 장면2는 열쇠 보유자와 상호 시선 상대가 협력해 문을 연다.

특정 표식 이름, 문장 순서, 정답 좌표는 강제하지 않는다. 표식 바꾸기와 중복/추가 관찰도 같은 의미면 허용한다. 대상 후보가 여럿이어도 최종 실행 상대 조합이 하나라면 실행한다.

실패는 세계를 바꾸지 않으며 조립을 수정하거나 되돌릴 수 있다. 성공 후 조립을 바꾸면 같은 장면의 시작 상태에서 재시험한다. 그 수정도 되돌려 완료 상태를 복원할 수 있다. 장면별 판/완료/힌트는 따로 저장한다.

## 대표 연결 — 스포일러

1번: ○→가지다→열쇠 / ○→보다→△ / △→내다→소리 / ○→열다→△.

2번: ○→가지다→열쇠 / ○→보다→△ / △→보다→○ / ○→돕다→△.

○와 △를 서로 바꾸거나 다른 표식으로 이름 붙여도 된다. 행동문 앞에 관찰을 놓는 표시 순서는 실행 조건이 아니다.
