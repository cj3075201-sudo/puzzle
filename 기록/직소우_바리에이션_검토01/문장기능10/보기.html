같은 말, 다른 연결 방식

문장에 영향을 주는 기능을 어디에 놓고, 어디까지 적용할까?
단어는 그대로 두고 부정·질문·선택·결합·조건을 세 방식으로 비교합니다.

01 / ATTACH

파랑에 기능 피스 연결

문장의 행동 조각을 기준으로
기능을 연결한다.

조작 제안 · 기능 글자를 모형에 넣고 해당 파랑에 접합. 두 문장이 필요하면 각각의 파랑을 연결.

얻는 것 · 기존 직소우 조립과 가장 가까움. 문장을 감싸거나 옮기지 않아도 됨.

걸리는 것 · 파랑에 기능용 접합부가 필요함. 파랑이 여럿이면 문장 전체인지 행동 하나인지 흐려질 수 있음.

02 / ENCLOSE

범위를 감싸는 띠

영향받는 표현의 범위를
밖에서 드러낸다.

조작 제안 · 기능 글자를 띠의 탭에 넣고 문장 범위를 선택. 두 문장은 각각의 띠를 이어 관계 지정.

얻는 것 · 어느 말 전체를 바꾸는지 가장 명확함. 기존 노랑·파랑 접합은 그대로 유지.

걸리는 것 · 범위 선택 조작이 추가됨. 공유 조각이 있으면 범위가 겹칠 수 있음. 자동 묶음 이동과는 별도.

03 / BRANCH

중심에서 문장 가지 연결

기능을 중심에 놓고
영향받는 문장을 가지로 붙인다.

조작 제안 · 중심 모형에 기능 글자를 놓고 문장 가지를 연결. 조건은 전제 가지와 결과 가지를 구별.

얻는 것 · 한 문장 기능과 두 문장 관계를 같은 구성 원리로 볼 수 있음.

걸리는 것 · 문장 하나를 가지로 연결하는 새 규칙이 필요함. 반복되면 배치가 커지고 중심 정답칸처럼 느껴질 수 있음.

WORKING RECOMMENDATION

우선 비교 기준은 02번. 문장 전체에 작용한다는 범위가 눈에 보입니다. 다만 띠를 만드는 조작이 번거롭다면 01번이 더 나을 수 있습니다. 색만 바꾸는 것이 아니라 적용 범위를 선택하는 판단이 생기는지 봐야 합니다.

WHAT THIS DOES NOT DECIDE

같은 보라색이어도 모든 기능이 같은 모형을 쓰지는 않습니다. 부정·질문은 한 내용, 선택·결합은 두 내용, 조건은 역할이 다른 두 내용을 다룹니다. ‘다음’ 순서안과 한정 ‘만’은 보류를 유지합니다.

화면의 한국어·A/B·해석은 설계 비교용입니다. 실제 게임의 자동 문장 번역을 제안하지 않습니다. 연결선은 관계를 보여주는 개념도이며 최종 직소우 접합 치수는 미정입니다. 버튼으로 기능·적용 문장·순서를 바꿀 수 있으며 자유 드래그 조립은 구현하지 않았습니다.
