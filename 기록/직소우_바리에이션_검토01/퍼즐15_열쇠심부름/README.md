## 목표와 규칙

책을 든 심부름꾼이 열쇠를 받아 관리인에게 가져간다. 열쇠를 가진 문지기는 복귀식 레버를 놓으면 통로가 닫혀 자리를 뜰 수 없다. 첫 대화 때 한 발 이동→통로 닫힘→레버 복귀를 보여준다.

가지다는 현재 보유 상태로 대상을 좁힌다. 주다는 두 갈래 입력이 주는 주체, 원형 입력이 받는 대상, 출력은 물건이다. 전달 대상 둘을 실행 전 상태에서 결정하고 소지품을 이동한다. 다음 발화는 변경된 상태에서 지칭 대상을 다시 구한다. 한 발화에는 주다 또는 가다 한 개와 보유 상태들을 조립한다.

| 조립/상태 | 결과 |
|---|---|
| 처음 열쇠 보유자 이동 | 문지기가 한 발 움직임→통로 닫힘→레버 복귀 |
| 열쇠 없는 심부름꾼 이동 | 관리인이 빈손을 가리킴→심부름꾼 복귀 |
| 열쇠 보유자가 책 보유자에게 열쇠 전달 | 열쇠가 이동하고 심부름꾼은 책도 유지 |
| 전달 뒤 같은 열쇠 보유자 이동 발화 | 이번에는 심부름꾼이 안으로 이동하여 완료 |
| 나를 경유한 전달 | 실제 소지품 상태에 따라 두 번 전달 허용 |
| 전달 뒤 책 보유자를 이동 대상으로 지정 | 열쇠를 지닌 심부름꾼이므로 완료 |
| 주체/수신자 모호함·같은 사람·없는 물건 | 상태 유지, 해당 문제에 맞는 반응 |

최종 승인 목표는 심부름꾼의 운반이다. 나를 거친 물건 전달은 가능하며 나의 이동으로 목표를 대신하지 않는다. 책도 전달 가능하므로 완료문구는 책 소지를 강제하지 않는다. 목적지 안/집→안 동등 수용, 노랑사슬3, 글자/모형 분리, 회전없음, 재사용 유지.

7열5행 조립판과 기존 실제 직소우 외곽을 사용한다. 조립 보관/불러오기는 편집 상태 하나를 저장하는 편의이며 조각 병합이나 새 언어 규칙이 아니다. 전달 전후 같은 발화를 다시 제출할 수 있다. 주민을 다시 클릭하거나 발화 탭을 선택하면 현재 소지품을 말한다.

## 검증

- core.test.js 24개 통과: 직접 전달·플레이어 경유·현재상태 필터·전달 전후 같은 이동 발화·책 보존·주체 표지·연결 누락·모호함·세계 불변성.
- Edge 브라우저 실제 DOM 조작 18개 통과: 8조각 직접 전달, 선행 레버 반응, 실패/복귀, 조립 보관과 같은 발화 재사용, 상태와 발화 갱신, 이동완료, 전달 중 재시작, 소리/Escape 조작 시 전달 소품 유지. browser-results.json 참조.
- 실제 새로고침 9개 통과: 전달 후 소지품·기존 책·조립판·보관 조립·발화 복원, 완료 상태와 위치/완료 패널 복원. reload-results.json 참조.
- 메인이 플레이/완료 캡처를 시각 확인했다. 독립 검토가 발견한 완료문구의 책 소지 강제와 전달 중 원본 열쇠 중복 표시를 수정했다. 플레이어 운반 관련 검토 의견은 사용자가 승인한 최종 심부름꾼 목표와 대조해 경유 전달만 허용하는 현재 범위를 유지했다.
- 사용자 플레이 피드백: “오오 나름 전거보다 조금 어려워지게 잘만들었어.” 이전 퍼즐보다 조금 높아진 난도와 제작 결과를 긍정적으로 평가했다. 어떤 조립/판단이 어려웠는지는 아직 구체적으로 확인하지 않았다.
