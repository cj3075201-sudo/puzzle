# 직소우 물리 조립 독립 검토

2026-09-26. 논의 중인 후보. 프로젝트 파일·Unity 코드 수정 없음. `/tmp`에서만 도형 생성과 검산.

## 결론

장면 담당의 양쪽 주민을 안/밖으로 특정하는 8피스 표본은 **정사각형 6모형**으로 물리 조립된다. 넓은 보내다 모형을 새로 가정할 필요가 없다. 이 6종은 아래 두 배치를 만드는 집합이지 본편 전체 문법의 최소 총수라는 주장은 아니다.

다만 A/B는 외곽을 유지하고 `안`과 `밖` 글자만 바꿔도 된다. 가지를 통째 떼어 교환한 것과 의미가 같으므로 둘 다 인정해야 한다. **이번 증거는 관계를 표현하는 조립이 성립한다는 증거이며, 가지를 움직이는 것만의 독립적인 퍼즐성이 증명된 것은 아니다.** 다른 외곽의 동등 표현도 실제 검산했다.

## 6모형과 좌표

모두 몸체 1×1. 좌표는 몸체 왼쪽 위, x 오른쪽/y 아래. N/E/S/W는 위/오른쪽/아래/왼쪽. `+` 탭, `-` 홈, `0` 평면. 표의 순서는 N/E/S/W. 회전 없음. 평면끼리 닿는 것은 문법 연결이 아니다.

| ID | 색 | N/E/S/W | 이 표본의 사용 |
|---|---|---|---|
| Y_S | 노랑 | 0 / 0 / + / 0 | 나 |
| Y_ES | 노랑 | 0 / + / + / 0 | 보내다 입력이면서 위치 관계에도 참여하는 주민 |
| Y_Wsocket_S | 노랑 | 0 / 0 / + / - | 보내다 출력이면서 위치 관계에도 참여하는 주민 |
| Y_Wsocket | 노랑 | 0 / 0 / 0 / - | 집 두 개, 같은 모형 두 번 재사용 |
| B_SEND_square | 파랑 | - / + / 0 / - | 보내다 |
| B_IN | 파랑 | - / + / 0 / 0 | 안/밖 모두 넣을 수 있는 위치 관계 |

| 피스 | A 좌표와 모형 | B 좌표와 모형 |
|---|---|---|
| 나 | (0,-1), Y_S | 같음 |
| 입력 쪽 주민 | (-1,0), Y_ES | 같음 |
| 보내다 | (0,0), B_SEND_square | 같음 |
| 출력 쪽 주민 | (1,0), Y_Wsocket_S | 같음 |
| 안 | (-1,1), B_IN | (1,1), B_IN |
| 안과 연결된 집 | (0,1), Y_Wsocket | (2,1), Y_Wsocket |
| 밖 | (1,1), B_IN | (-1,1), B_IN |
| 밖과 연결된 집 | (2,1), Y_Wsocket | (0,1), Y_Wsocket |

두 집 피스가 다른 건물이라는 규칙은 없다. 같은 집을 문맥상 다시 지칭해도 된다. 주민 두 피스 역시 복제했다는 이유만으로 자동 별개 대상이 되지 않는다. 안/밖의 관계와 장면이 지칭을 나눠야 한다.

보내다의 N홈과 W홈은 동등한 입력이다. 위의 나/입력 쪽 주민 중 행위자와 보내지는 대상은 이 외곽만으로 정해지지 않는다. 출력 쪽 주민만 보내다의 출력으로 정해진다. 탭 전체를 행위자 표시로 바꾸지 않는다.

## 실제로 다른 외곽도 가능

B의 출력 쪽 주민을 `N탭+W홈` 모형으로 교체하고, 안은 (1,-1)의 `S홈+E탭` 모형, 그 집은 (2,-1)의 기존 W홈 모형에 둔다. 나머지는 B와 같다. 입력 주민의 밖 가지는 아래, 출력 주민의 안 가지는 위에 놓인다. 회전 없이 겹침도 없고 모든 탭·홈이 맞는다.

이 대체 배치는 추가 모형 2종을 사용하므로 A/B와 함께 제공하면 집합 8종이다. 같은 의미의 유효 표현으로 인정할 예시이지 추가 모형을 반드시 쓰게 할 이유는 없다. 정답의 외곽을 고정하거나 ‘정해진 가지 이동 방식만 성공’으로 판정하면 기존 기준을 위반한다.

## 실제 조작에서 남는 판단과 한계

처음 4피스 전달 골격에서 양쪽 주민을 특정하려면, 입력 주민의 1탭 외곽을 2탭 외곽으로, 출력 주민의 1홈 외곽을 1홈+1탭 외곽으로 바꾸어야 한다. 같은 주민이 전달과 위치 두 관계에 참여한다는 구조가 이 선택에 드러난다. 안/밖 글자를 아무 빈 칸에 넣는 것만으로 지칭이 정해지지는 않는다.

그러나 두 가지가 이미 완성되어 있는 A를 B로 고칠 때는 `안/밖 글자 교환`이 최단이며 유효하다. 이 장면에서 매번 외곽 교체나 가지 이동을 필수 노동으로 만들지 않는 것이 맞다. 가지 이동은 묶음을 이해·수정하는 조작상의 선택이다. 뜻을 결정한 뒤에도 별도의 공간 문제를 반드시 풀게 하는 구조는 이번에 제시하지 못했다.

권장 판별은 ‘아무 문장 틀도 주지 않은 상태에서 어느 주민에 어떤 관계를 연결할지 판단할 수 있는가’와 ‘완성한 뒤 다른 문맥에서 안/밖의 소속을 정확히 바꾸는가’다. 글자 교환만으로 성공한 플레이도 유효한 소통이다. 형상 선택의 재미를 주장하려면 그 이후 실제 조작 관찰이 필요하다. 새 공급 제한·좁은 판·숨은 유일 외곽을 넣는 것으로 이 한계를 덮지 않는다.

## 다른 비교 표본

| 표본 | 피스 수 | A/B에 필요한 색상 포함 모형 수 | 의미 |
|---|---:|---:|---|
| 정사각형 상태 가지: 나/주민/보내다/너/아프다 | 5 | 7 (순수 외곽 6) | 나와 주민 중 어느 쪽에 상태가 붙는지 |
| 같은 상태 가지, 보내다를 2×1로 하고 위에 두 입력 | 5 | 5 | 새 넓은 모형 가정을 허용하면 방향 교체 감소 |
| 기존 물/너에 안→집을 옮기는 표본 | 6 | 7 | 물의 위치/상대의 위치를 구별 |
| 양쪽 주민 특정, 정사각형 | 8 | 6 | 양쪽 가지가 공통 모형을 반복 사용 |

피스 수가 줄어도 방향별 외곽 수가 반드시 줄지는 않는다. 정사각형 5피스 표본 A→B에서는 노랑 두 개 외곽뿐 아니라 아프다의 N홈→W홈 외곽도 교체해야 한다. 그래서 상태 단어 하나를 줄인 것이 무조건 더 간단한 조작이라는 초기 가정은 수정했다.

메인이 전달한 넓은 보내다 8피스 좌표도 검사 통과했다. 그 배치는 8모형이다. 물리 불가능한 안이 아니라, 이 표본에서는 정사각형 6모형보다 새로운 형상 가정과 종류 수가 많은 안이다.

## 검산 증거와 미해결

- 몸체 사각형에 목 너비 0.13, 원 중심 거리 0.16, 반지름 0.12의 실제 돌출 도형을 합치고, 홈에는 대응 도형을 뺐다. 원은 사분면당 64개 선분으로 근사했다. 추상 그래프만 확인한 것이 아니다.
- 위 8피스 A/B/다른 외곽 B와 메인의 넓은 모형 좌표는 각각 7접합, 양의 면적 겹침 0건, 미짝 연결부 0개, 연결체 1개다. 모든 개별 다각형이 유효하다.
- 보조 표본들을 포함해 정상 배치 10개 통과. 상태 피스만 옮기고 대상 외곽을 바꾸지 않은 대조는 미짝 연결부 2개로 실패했다. ‘도형끼리 안 겹치니 조립 성공’이라는 잘못된 판정을 피한다.
- 한국어는 뜻을 보여주는 도식용 표기다. 홈을 피하도록 글자 위치를 옮긴 도면을 직접 열어 확인했다. 본편 문자·UI 크기·마우스 조작을 검증한 것은 아니다.
- 구현, 드래그 경로·스냅·교체 UX, 지칭 판정 전체, 초견 이해와 재미, 본편 어휘 확장성은 검증하지 않았다.
