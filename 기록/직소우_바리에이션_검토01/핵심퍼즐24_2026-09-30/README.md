## 이번 산출물과 유지 범위

- 후보를 비교한 뒤 서로 다른 사고방식의 독립 HTML 핵심 표본을 만든다. 본편 Unity 제작이나 새 문법의 본편 채택이 아니다.
- 일대일로 선택한 상대만 듣고 자기 행동을 수행한다. 다른 공간의 크리처가 자동 수신하거나 중앙 관리인이 모두를 조종하지 않는다.
- 모형/글자 분리, 회전 없음, 노랑/파랑, 노랑 사슬3 이하, 기존 주다 주체 표지 기준을 유지한다. 대화창이 직소판이고 우측이 모형/글자다. 월드에서 상대/물건을 직접 클릭한다.
- 기본뜻은 한국어로 확인하되 전체 발화의 관계·의도를 플레이어가 판단한다. 소리 순서/타이밍 해독은 필수로 넣지 않는다.

## 합격을 판단할 것

- 표현을 선택할 이유가 대화 상대를 클릭한 뒤에도 남는가.
- 관찰→해석→행동→새 관찰이 앞선 계획을 재검토하게 하는가. 처음부터 주어진 표/절차에서 단일 답을 고르는가.
- 기존 전략의 이름/단어만 치환해서 해결되는가. 새로운 선택·상태 관계가 실제로 필요한가.
- 합리적인 대안은 수용하는가. 새 문법을 안 썼다고 실패시키거나 질문 완료 플래그로 통과를 잠그지 않는가.
- 실패 반응이 가설을 구별할 정보를 주는가. 문법·조립·이동으로만 오래 걸리지 않는가.
- 핵심 장면10~20분은 AI가 제안한 사람 해결 경험의 설계 목표다. 측정치나 사용자 확정 하한이 아니다. AI 시간을 사람 시간으로 환산하지 않는다.
