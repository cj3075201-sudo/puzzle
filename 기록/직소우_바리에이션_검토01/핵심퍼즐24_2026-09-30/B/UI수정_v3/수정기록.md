# B v3 — 기록원의 시야를 보여주는 칸막이

초견12 완료 후의 시각 보완. 기록원의 현재 자리를 안쪽 작업석과 말을 건네는 창틀로 표시하고 운반로 뒤쪽 벽에 이어진 칸막이 선을 추가했다. 정보·문법·상태 전이·해답·저장키는 변경하지 않았다. frozen12는 부모 보관본 그대로이며 이 폴더에 수정 전 HTML/scene.js도 보존했다.

scenarios.js/core.js/models.json/app.js 네 파일의 수정 전후 SHA256이 동일함을 확인했다. 변경은 scene.js 배경 도형과 이에 따른 HTML 재생성이다. scene.diff와 HTML_해시.json, 의미파일_해시.json에 근거를 보관했다.

Chromium에서 NPC 중앙과 운반함 중앙을 실제 포인터 mousePressed/mouseReleased로 클릭했다. NPC listener=clerk, 운반함 설명창으로의 전환 2건 통과. 시야칸막이_검증.png를 직접 확인했다. 이는 제작자 시각/포인터 회귀 검사이며 새로운 초견 플레이 또는 난도 검증이 아니다.
