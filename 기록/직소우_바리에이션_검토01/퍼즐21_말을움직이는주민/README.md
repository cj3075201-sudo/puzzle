# 말을 움직이는 주민 · 퍼즐21

2026-09-29. 사용자 “응 새로운거를 추가해도되니까 만들어서 보여줘” 승인으로 제작한 독립 HTML 플레이 표본.

[플레이 열기](플레이.html). 파일 하나로 실행하며 서버·인터넷 연결이 필요 없다. 기존 모형/글자 분리, 실제 직소 외곽과 접합, 회전 금지, 비소모 모형, 노랑 연속 세 조각 제한을 유지한다.

## 이번 신기능

1. **말의 조각을 행동 대상으로 지정**: 문은 세계의 문, 글자→문은 부탁판의 문 조각. 같은 이름은 위/아래 등으로 구별한다.
2. **계속 읽는 부탁판**: 내 부탁을 먼저 실행한 주민은 자신의 판을 다시 읽는다. 시작 주민 조각에 이어진 성분만 실행한다.
3. **자기 부탁 변경**: 주민이 자신의 시작 조각을 옮기면 새로 이어진 부탁을 읽는다. 움직임과 다음 행동을 순서대로 표시한다.

새 문법은 이번 표본의 시험 규칙이다. 발화 사이 실제 공유 조각은 이번 구현에 포함하지 않았다. 본편 Unity 보류 유지, 사람의 재미/놀라움 평가는 다음 사용자 플레이에서 받는다.

## 장면과 판정

- 목표: 주민이 부탁판을 읽고 문을 열어 주게 만들고 출입문을 클릭해 건넌다.
- 상황: 유리 너머 부탁판은 주민만 만질 수 있다. 플레이어는 내 말에서 자유 조립해 이동을 부탁한다. 상자도 같은 옮기다 행동으로 움직일 수 있다.
- 시작: 주민→닫다→문이 연결되어 있다. 떨어진 옮기다→아래→글자→주민과 열다→문 조각이 남아 있다. 마지막 문 조각은 한 칸 떨어져 있다.
- 공개 단서: 현재 읽는 연결은 짙은 테두리, 시작점은 작은 ▶, 글자 지칭 안의 설명은 점선. 위치·모형·모든 단어를 볼 수 있다.
- 실행: 내 말 실행 → 부탁판 재해석 → 실제 조각 이동 시 재해석. 최대 여덟 단계와 반복 감지로 무한 반복을 멈춘다. 타이밍 조작은 요구하지 않는다.
- 출입: 문 앞에 도착하면 주민이 문을 닫고 부탁판을 다시 확인한다. 현재 부탁이 유효한 열다→문이면 문을 열어 통과시킨다. 이 행동은 클릭 반응과 이벤트에 표시한다.
- 동등 표현: 옮기다 아래에 방향/대상을 형제로 달거나 방향→대상으로 잇는 방식 모두 허용. 글자 중복은 현재 위치 수식으로 특정한다. 글자 설명 안의 조각은 해당 이름을 지칭할 때 제외하며 연결이 끊어지면 다시 대상이 된다.
- 물리 제약: 실제 접합 모양, 범위, 겹침 검사. 이동 때문에 홈/돌출이 맞지 않으면 이유를 알려 주고 원상태를 유지한다.
- 실패와 재시도: 문법/지칭 모호성/불가능 이동 각각 피드백. 되돌리기는 조립과 세계 행동 전체에 적용된다. 출구 실패에서 실제로 바뀐 문 상태도 저장·되돌리기에 포함한다.
- 종료: 특정 좌표 배열이나 발화 순서를 비교하지 않고 현재 읽히는 뜻과 문 상태를 검사한다. 최종 문 조각을 나중에 고쳐도 진행되며 다른 유효한 열다 연결도 허용한다.

## 대표 풀이 — 스포일러

1. 주민→옮기다(글자→아래→문, 왼쪽): 아래쪽 문 글자를 열다 옆으로 옮긴다.
2. 주민→옮기다(글자→주민, 아래): 시작 주민을 아래 한 칸 이동한다.
3. 같은 말을 다시 한다. 시작 주민이 중간 부탁에 연결되고, 주민이 그 부탁에 따라 자신의 시작 조각을 한 번 더 내린다. 마지막 열다→문을 읽고 문을 연다.
4. 세계의 문을 클릭해 건넌다.

첫 단계와 마지막 수리 순서는 고정하지 않는다. 자기 변경을 거치지 않는 다른 유효한 부탁판 배치도 통과한다. 대표 풀이의 재미 평가는 아직 받지 않았다.
