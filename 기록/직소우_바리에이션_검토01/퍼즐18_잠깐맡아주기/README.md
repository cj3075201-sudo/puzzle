## 목표와 규칙

처음 안쪽 주민은 열쇠, 바깥 주민은 책을 가지고 있다. 서로 물건을 바꿔 안쪽 교환함에는 책, 바깥 교환함에는 열쇠를 넣는다. 이 교환소의 주민 교환함은 한 칸씩이며 이미 차 있으면 물건을 받지 않는다. 주민 전체의 소지량을 바꾸는 규칙이 아니라 이번 장면의 보관 규칙이다. 플레이어는 물건 두 개를 임시로 맡을 수 있다.

최단 대표: 안쪽 주민→나 열쇠, 바깥 주민→안쪽 주민 책, 나→바깥 주민 열쇠. 책부터 맡는 대칭 3회 경로, 두 물건 모두 맡아 4회 전달하는 경로, 원래 주인에게 되돌린 뒤 재시도하는 경로도 허용한다. 최단 횟수 강제 없음. 주민 위치는 고정, 자동 교대 없음.

주다 표시된 두갈래 입력=주는 주체, 원형 입력=받는 대상, 출력=물건. 현재 위치/보유 상태로 실제 대상을 특정한다. 빈칸만 보고 애매한 주민을 자동 선택하지 않는다. 모형글자 분리, 회전없음, 노랑사슬3 유지. 한 발화에 행동 하나, 동시 물건 교환을 자동 처리하지 않는다.

화면에서 안쪽 교환함/바깥 교환함/내 물건을 모두 표시하고 꽉 찬 수신자의 칸을 강조한다. 실패하면 세계와 조립 유지. 전달 도착 후 저장, 도중 재시작은 이전 초기 상태로 복귀. localStorage grad.puzzle18.v1로 이전 표본 저장과 분리.
