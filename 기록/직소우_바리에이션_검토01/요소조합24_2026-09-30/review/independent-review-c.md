# 요소조합24 독립 의미·UI QA

설계를 미리 본 AI의 독립 QA다. 사람 초견 검증이나 재미 검증으로 해석하지 않는다. 게임 코드 및 기존 기록은 수정하지 않았고 자체 검증 자료만 review/에 저장했다.

결과: 실제 화면에서 모형 선택→칸 배치→글자 삽입→말하기를 수행해 6/6 완료했다. 힌트는 사용하지 않았다. NPC가 보여 주는 세로 조립과 다른 가로 7조각 배치도 판정을 통과했다. 각 완료 증거는 종4 뒤 1500ms 대기한 화면이며 실제 수문과 4/4 표시도 확인했다.

03 자리 기준은 2·3칸 실패하고 ○ 결속으로 복구했다. 04 같은 실물 ○는 2·3칸 실패하고 현재 왼자리 기준으로 복구했다. 05 시작 위치에서는 네 칸 모두 미관측 실패였으며, ○ 보랏등 결속과 오른→왼→왼→오른 관측 이동을 결합해 통과했다. 06 이전 ○ 정책은 3·4칸 미관측 실패였고 앞등 기준으로 통과했다. 실패 마지막 칸이 통과하면 최신 피드백만으로 누적 실패를 놓칠 수 있으나, 공개 일정의 실제 시험 표는 실패 칸을 표시한다.

저장: 03 2/4에서 재로드한 화면 133은 정책·○·조각·진도를 유지했고 이후 완료했다. 브라우저 프로세스 종료 후 같은 프로필로 접속한 327은 완료 목록, 329/331은 완료된 03 월드와 조각을 복구한다. 05와 06은 900폭에서 실제 조립·이동·종 누르기를 완료했고, 1536폭 화면도 직접 봤다. 작은 폭에서는 스크롤로 대화/모형/글자를 오가야 하며, 펼친 일정표는 조립판을 아래로 밀지만 접근은 가능하다.

의미 검산: 최종 state SHA 7621bdcc…에서 자체 31/31 통과. 실제 출력 비교, 03↔04와 05↔06 이전 전략 실패, 닫다/꺼짐 동등 정책, 매틱 무조건 지속정책 갱신 우회 차단, 1회 요청과 지속정책 분리, 복수 행동 거부를 별도로 검산했다. 상태 QA를 UI 성공으로 세지 않았다.

인과 판단: 03↔04는 같은 ○가 도움이 되는 실물 추적과 방해가 되는 자리 추적을 비교한다. 05↔06은 같은 고정 실물 참조가 관측 이동을 요구하는 경우와, 현재 관찰 대상이 바뀌어 앞등으로 교체해야 하는 경우를 비교한다. 05는 결속·자리 교환·시야·조건이 한 대표 풀이에서 연결된다. 다만 대표 경로의 결합을 검증한 것이며 모든 요소가 모든 대안 풀이에 필수라는 증명은 아니다. 01↔02는 작은 반전 수업이다.

정책 변경 시 시험 진도 초기화는 공개된 한 지속 부탁의 네 변화 검증 목적에는 타당하다. 이동과 결속은 진도에 영향을 주지 않는다. 이 제한을 본편의 자유로운 실시간 부탁으로 그대로 옮기는 것은 별도 설계 판단이다. 클릭한 상대는 수리 1명이며 목표 등·관측 대상은 발화와 월드 변화로 달라져 NPC 클릭만으로 해결되지 않는다.

검증 버전: 6전체 UI 경로는 HTML 8fc2c2e5…에서 수행했다. 최종 HTML은 179427d0…이며 수문 한글 라벨과 완료 복귀를 최종 재로드에서 추가 확인했다. 옛 브라우저 DOM은 종료되었으므로 사후 엔진 해시 복구를 주장하지 않는다. 최종 실제 DOM의 내장 script 해시는 embedded-final-hashes.json에 별도 저장했고, core/state/levels/scene/app 모두 현재 원본 파일과 정확히 일치했다. model-data는 생성된 첫 script로 독립 원본 JS 파일과 비교하는 대상이 아니다.

QA 도구 오류 두 건(빈 판의 비활성 clear, PTY의 긴 한줄 JSON 절단)은 루틴을 수정해 해결했다. 대표 경로를 막는 게임 오류는 발견하지 않았다. source injection이나 loadForTest는 실제 플레이에 사용하지 않았다.
