# 같은 요소, 다른 부탁 — 요소 조합 24

2026-09-30 · HTML 시험 퍼즐 6개 · **제작·검증 완료**

[플레이 열기](플레이.html). 01부터 진행하면 새 규칙과 재조합을 비교할 수 있다. 한 장면에 청자는 수리 한 명이다. 모형·글자를 따로 골라 실제 직소를 자유롭게 조립한다. 회전은 없다. 레벨별 자동 저장, 조립 되돌리기, 재시작을 제공한다. 월드의 일정표를 누르면 등 교대와 목표를 미리 볼 수 있다. 시험종은 시간 한 칸을 진행한다. 지시판의 부탁을 바꾸면 새 부탁을 처음부터 시험하며, 이동과 ○ 결속은 시험 사이에도 바꿀 수 있다.

사용자 요청: “새로운 요소를 추가해도되고, 아니면 참신한 변주를 줘도되니 여러퍼즐을 만들어봐”. 앞선 요구인 기존/신규 요소의 반복 재조합을 플레이 가능한 묶음으로 구현한다. 새 조건·참조·관찰 규칙은 이번 HTML 시험안이며 본편의 확정 문법이 아니다.

## 공통 요소

1. **지속되는 부탁**: 지시판의 말을 고치면 다음 순간에도 수리가 그 부탁을 읽는다. 일회 행동과 효과가 다르다.
2. **동일 실물 표식 ○**: 시작 위치를 붙잡는 대신 특정 등 자체를 가리킨다. 등이 자리를 바꾸어도 같은 등이다.
3. **조건**: 등 상태가 바뀌면 수문의 동작도 바뀐다. 조건 반전과 동작 반전의 동등 표현을 허용한다.
4. **시야**: 수리는 자신에게 보이는 등의 상태로 조건을 판단한다. 플레이어가 보는 전체 화면과 구분한다.

## 레벨 구성

| 레벨 | 조합 | 다시 판단할 것 |
|---|---|---|
| 01 | 지속 + 조건 | 지금 문을 한 번 여는 것과 다음 상태까지 부탁하는 것의 차이 |
| 02 | 지속 + 조건 | 켜졌을 때 열던 부탁을 꺼졌을 때 열도록 바꾸기 |
| 03 | 지속 + 동일 실물 + 조건 | 등 위치가 바뀌면 위치 이름이 다른 실물을 가리킴 |
| 04 | 지속 + 동일 실물 + 조건 | 이번에는 현재 위치가 중요해서 동일 실물 고정이 방해함 |
| 05 | 지속 + 동일 실물 + 조건 + 시야 | 특정 등을 계속 추적하면서 그 등 상태를 볼 자리를 확보함 |
| 06 | 지속 + 조건 + 시야, 동일 실물과 비교 | 앞에서 보는 등을 따라야 하므로 이전의 고정 대상 추적 전략을 버림 |

01–02는 기초 소개와 반전 연습이다. 깊이 증가의 중심은 03–04의 실물/위치 선택과 05–06의 대상 추적/관찰 결합이다. 여섯 개가 모두 직전보다 어렵다는 뜻으로 순서를 붙이지 않았다.

## 이번 판단

단순한 글자 순서 교체보다, 어떤 대상을 계속 가리킬지와 NPC가 무엇을 볼 수 있는지가 실제 선택을 바꾼다. 05에서 네 요소를 함께 쓰고, 06에서는 고정 대상을 버리는 편이 맞는다. 재미와 난도는 사용자가 이 비교를 플레이해 판단할 다음 항목이다.

등은 두 개, 시험은 네 칸인 작은 신호실이다. 조건 반전과 동작 반전은 같은 출력을 낼 수 있고, 시험 중 ○를 다시 묶는 대안도 수용한다. 특정 표식 사용이나 대표 경로만을 정답으로 강제하지 않는다. 01–02는 기초 연습, 03–04는 참조 비교, 05는 통합, 06은 상대 관찰로 전략을 다시 고르는 구성이다.
