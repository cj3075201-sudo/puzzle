# 관계 표지 05 — 긴 연결·문맥 부담·새 색 비교

2026-09-27 · 사용자 요청에 따른 설계 검토. 새 색·관계 글자·기본문형·종별 스타일은 미채택이며 게임 구현은 하지 않았다.

## 사용자 우려와 현재 추천

사용자는 긴 노랑 사슬을 실제 게임에 넣었을 때의 복잡함, 맥락을 통한 해석을 플레이어가 따라올 수 있을지, 조사 관계를 명시하는 새 색의 가능성을 제기했다. 긴말/분기형을 크리처별 특성으로 둘 가능성도 제안했고, 에이전트로 읽기를 테스트하자고 요청했다.

**현재 추천은 짧고 읽기 범위가 안정된 기본 발화에, 필요한 관계를 명시할 수 있는 선택 표지를 더하는 안을 우선 비교하는 것이다.** 기존의 ‘모든 조사 관계를 문맥으로 읽는다’에서 ‘명시된 관계는 그대로 읽고, 생략된 관계는 문맥으로 보충할 수 있다’로 조정하는 후보다. 사용자가 원래 기준을 폐기하거나 이 후보를 채택했다고 기록하지 않는다.

## 1. 긴 노랑 사슬과 크리처별 스타일

- 현재 A는 집→안→주민→열쇠→찾다라는 긴 경로이며 B는 일부가 분기한다. 단순히 길이를 줄이거나 세로로 배치해도, 소유·행위 참여·장소의 적용 범위가 불명확하면 읽기 부담은 남는다. 간접 연결된 노랑을 행동 참여자로 읽을 수 있다는 후보도 어디까지 가능한지 정해야 한다.
- A를 모든 발화의 기본형으로 삼는 것은 현재 추천하지 않는다. 짧은 기본 발화를 먼저 안정시키고 긴 설명이 필요한 장면에서 확장형을 비교한다. 아직 ‘노랑 최대 몇 개’ 같은 강제 제한이나 최종 피스 수를 정하지 않는다.
- 종별 긴말/분기형 차이는 후보로 유지할 수 있다. 다만 **같은 뜻을 보존하는 서로 다른 표현**을 만든 뒤 스타일로 비교해야 한다. 현재 사용자 읽기의 A는 주민의 위치, B는 열쇠의 위치를 말하므로 그대로 같은 뜻의 두 말투라고 취급할 수 없다.
- 같은 공통 문법 안에서 관계를 명시하는 습관·생략하고 행동으로 보충하는 습관·여러 번 나누어 말하는 습관을 검토한다. 종마다 연결의 뜻을 바꾸거나 특정 종의 말을 항상 한 방식으로만 풀도록 고정하지 않는다.

## 2. 새 색의 역할과 세 후보

색은 ‘관계 표현’이라는 종류를 나타내고, 안의 글자와 실제 접합은 어떤 관계를 명시하는지 나타낸다는 후보를 둔다. 최종 색상은 미정이다. 한국어 조사를 전부 복제하는 목록이나 전용 색을 하나씩 배정하는 안을 전제하지 않는다.

| 방식 | 기대할 수 있는 이점 | 확인할 비용·한계 |
|---|---|---|
| 표지 없이 문맥으로 읽기 | 조각 추가 없이 관찰과 소통을 유지 | 단서가 대칭적이면 특정 역할을 알 수도 표현할 수도 없을 수 있음 |
| 모든 주요 관계에 표지 필수 | 명시한 역할이 안정되고 말을 정확히 전달하기 쉬움 | 단순 발화에도 조각·학습·조작이 추가됨. 명시하지 않은 범위 문제까지 해결하지 않음 |
| 필요할 때 명시하는 선택 표지 | 익숙한 발화는 짧게 쓰고 애매하거나 기존 예상과 다른 역할을 드러낼 수 있음 | 표지가 없으면 계속 오해하는 설계라면 사실상 매번 붙이는 부담이 됨. 표지 생략/충돌/재사용 규칙도 필요 |

우선 비교할 표지는 **‘이 행동을 하는 쪽’ α 하나**다. 대상과 파랑 행동 사이에 놓으면 그 대상이 해당 행동의 행위자임을 명시한다. 예를 들어 보내다의 동등한 두 입력인 나/주민 중 주민과 보내다 사이에 α를 넣으면, 주민이 보내는 쪽이라는 정보를 추가한다. 앞선 A처럼 파랑에 닿지 않은 주민에도 아무 위치에서나 이 표지를 붙이면 된다고 가정하지 않는다. 구체 접합 외곽은 아직 제작하지 않았다.

비교 문형 S는 나·주민·보내다·너 4피스이고 α 하나를 추가하는 안은 5피스다. 이는 이 예시의 요소 수이며 다른 문형의 최종 개수나 제작 시간 추정이 아니다. 새 색으로 나뉘어 보일 수 있어도 조각 수는 늘므로 가독성 개선을 자동으로 주장하지 않는다.

표지의 후보 처리 원칙은 다음과 같다.

- 표지가 명시한 관계는 해석의 제약으로 유지한다. 주변 자세가 다른 역할을 예상하게 하더라도 표지를 몰래 반대로 읽지 않는다. 말의 뜻·상대의 수락·실행 가능성은 구별한다.
- 표지 생략은 추가 정보가 없다는 뜻이다. 생략했으므로 반대 역할이라는 암묵 규칙을 만들지 않는다.
- 같은 문형에서 양립할 수 없는 두 표지를 붙이면 마지막 입력만 정답으로 취급하거나 두 사건으로 자동 분해하지 않는다. 어느 부분이 충돌했는지 드러낼 방법이 필요하다.
- 플레이어가 원해서 자주 명시하는 것과, 게임의 판정이 불공정해 명시를 강요받는 것은 구별한다. 명시 표현을 일부러 틀리게 처리하거나 피스 소모·종별 이해 불가로 막아 문맥 해석을 강요하지 않는다.
- 배우기 전 뜻을 추측하는 경험, 모형의 무제한 재사용, 한국어 전체 문장 자동 번역 금지는 유지한다. 표지 도입이 말의 의도·진실성·지칭을 전부 자동 해설한다는 뜻은 아니다.

## 3. 독립 읽기 검토 결과

검토 자료: [정답을 싣지 않은 관찰 자료](독립검토05/관찰자료.md). `relation_reader_05`를 대화 이력 없이 시작해 이 파일만 제공했다. 기본 글자와 α의 뜻은 이미 배웠다는 가정 아래, 6개의 보내다 사례와 1개의 찾다 확장 사례를 읽게 했다. 실제 글자 학습·모형 조작·시각 가독성·사람 경험을 테스트한 것은 아니다.

| 사례 | 검토자가 읽은 결과 |
|---|---|
| Q: 무표지, 역할 단서 없음 | 나/주민 중 누가 보내는지 결정할 수 없음 |
| F: 무표지, 주민이 출발 준비하고 나는 도착 대상을 가리킴 | 내가 주민을 보내는 해석이 유력하지만, 준비 자세만으로 다른 제안을 배제하지 않음 |
| N: 나 쪽에 α | 내가 주민을 보냄 |
| W: 주민 쪽에 α | 주민이 나를 보냄 |
| J: 주민이 출발 준비하지만 주민 쪽에 α | 주민이 나를 보내는 말로 읽음. 자세와 달리 새 계획을 제시할 수 있으며, 이를 실행 불가나 역할 반전으로 자동 처리하지 않음 |
| D: 동등한 두 입력 모두에 α | 한 명이 다른 한 명을 보낸다는 이 문형 조건과 충돌. 마지막 표지만 유효하다고 고르지 않음 |
| X: 주민—α—찾다—열쇠, 집→안→열쇠도 연결 | 주민이 찾는다는 역할은 정함. 집 안에 열쇠가 있다는 뜻인지 집 안에서 찾는다는 뜻인지는 범위 규칙이 없어 정하지 못함 |

이 검토는 **관계 표지가 명시한 역할을 구별할 수 있고, 남은 범위 문제는 별개라는 점**을 보여주는 규칙 점검이다. 표시 뜻을 이미 알려줬으므로 처음 본 플레이어가 쉽게 배운다거나 재미있게 읽는다는 근거로 쓰지 않는다. 무표지 사례가 존재한다는 것만으로 실제로 생략하며 플레이할 수 있다는 것도 입증되지 않았다.

별도 설계 검토를 맡은 `jigsaw_geometry`는 선택 표지를 우선 비교할 것을 추천하면서, 표지가 사실상 상시 필수 입력이 되는 위험과 명사 연결 범위를 별도로 정해야 한다는 점을 지적했다. 종별 스타일은 같은 지칭·관계를 보존해야 한다는 지적도 반영했다.

## 다음 시스템 비교

현재 결과만으로 역할 표지 하나를 본편 색으로 확정하지 않는다. 다음 구체화는 짧은 기본 발화에 같은 내용을 무표지/선택 표지로 표현하는 접합 도면과 읽기 범위다. 실제 조립 상태에서 빈 연결부, 들어오는 경로, 표지의 적용 행동이 분명한지 본다. 긴말/분기형 스타일은 동등한 뜻을 유지하는 표현을 만든 뒤 비교한다. 사용자에게 사람 테스트 모집이나 코드 구현을 다음 진행의 선행조건으로 요구하지 않는다.
