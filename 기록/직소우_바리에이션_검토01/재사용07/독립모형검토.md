# 제한 모형 메뉴 — 독립 검토

2026-09-27 · 최신 비교안 기준. 본편 구현·전체 문법 채택·재미 검증은 아님.

사용자 승인 범위는 무표지 문맥/연결부 형상의 좁은 비교와 대화별 모형 목록 제한이다. 새색 독립 피스 제외, 접합 표식 보류를 유지한다. 발견 모형의 누적·비소모와 글자/외곽 분리·회전 금지도 유지한다.

## 수량과 재사용

| 메뉴 | 파랑 외곽 | 노랑 외곽 | 합계 |
|---|---|---|---:|
| 보내다 | W/N 원형홈+E돌출, N만 두 갈래홈인 변형 | E원형돌출, S원형돌출, S두갈래돌출, W원형홈 | 6 |
| 밀다·당기다 공용 | W/N 원형홈, W만 두 갈래홈인 변형 | E원형돌출, E두갈래돌출, S원형돌출 | 5 |
| 아프다 | W원형홈 한 개 | E원형돌출 | 2 |

- 중복 제거한 기본 집합은 **파랑 5종+노랑 5종=색상 포함 낱개 모형 10종**이다. 아프다의 파랑 W홈과 노랑 W홈은 순수 외곽이 같으므로 도형만 세면 9종이다. 색과 의미 범주는 구별한다.
- 파랑 어휘는 4개, 연결 구조는 3종(입력2+출력1 / 입력2 / 입력1)이다. 추가 역할 형상은 능동행동의 행위자 1종이다. 원형은 중립이며 상태문에서 피동자를 뜻하지 않는다.
- 밀다→당기다는 이번 표본의 입력 수·배치·역할 규칙이 같아 **메뉴 5종과 완성 조립 외곽 전체**를 재사용한다. 다른 동사라는 이유만으로 항상 같은 파랑 외곽을 쓸 수 있다는 뜻은 아니다.
- 보내다→밀다·당기다는 **행위자 표시 규칙과 노랑 E/S 원형돌출 2종**을 재사용한다. 출력 유무·표시 방향이 달라 파랑 외곽은 그대로 재사용하지 않는다. 아프다에는 노랑 E원형돌출을 재사용한다.
- 이전 N형 공통안의 9종을 최신 메뉴 수에 혼용하지 않는다. 최신 기본 집합은 보내다 N형/밀다·당기다 W형의 10종이며, 단어 수만큼 모형을 복제하지 않는다.

## 도달 가능한 표현과 물리 검산

파랑의 몸체 왼쪽 위를 (0,0), W 입력 노랑을 (-1,0), N 입력 노랑을 (0,-1), 보내다의 출력 노랑을 (1,0)에 놓는다. 몸체는 모두 1×1이다. 아프다는 파랑과 W 입력 노랑만 사용한다.

- 보내다의 N두갈래에는 S두갈래 노랑, 밀다·당기다의 W두갈래에는 E두갈래 노랑이 맞는다. 다른 입력은 원형이다. 회전하거나 메뉴 밖 모형을 쓰지 않는다.
- 두 입력의 나/주민 글자를 교환하면 각 행동에서 **나가 주민에게 작용 / 주민이 나에게 작용**하는 두 의도를 모두 명시할 수 있다. 보내다의 출력 너는 이번 검산에서 고정했다.
- 원형 파랑과 원형 노랑 두 개도 메뉴에 있어 무표지 표현이 가능하다. 무표지의 글자 자리 교환은 동등 입력의 순서를 바꾸는 것이며 별도의 새 의미 두 개로 세지 않는다. 아프다는 나/주민 각각을 상태 대상으로 표현할 수 있다.
- 관계표시06의 실제 원형/두 갈래 다각형 생성 함수를 읽기 전용으로 사용하여, 위 메뉴의 **14배치**(세 행동×무표지/명시×글자교환 2, 상태 대상 2)를 메모리에서 검사했다. 서로 다른 물리 배치는 5종이며 나머지는 글자 재사용·교환 사례다. 사용 모형은 각 메뉴에 포함되고, 모든 포트는 한 번씩 맞으며, 양의 면적 겹침이 없었다. 검사로 출력 파일·GUI·본편 파일을 변경하지 않았다.

## 제한 메뉴의 효과와 남는 확인

- 서로 반대 의도인 장면에도 메뉴·순서·이름을 동일하게 제시해야 한다. 숨은 정답에 따른 모형 활성화·추천·노랑 글자 고정은 하지 않는다. 현재는 메뉴 설계를 검토했으며 새 HTML의 표시 방식까지 검사한 것은 아니다.
- 보내다 N형/밀다 W형은 ‘항상 위가 행위자’라는 전역 암기를 깨지만, ‘동사별 고정 위치’ 암기를 배제하지는 못한다. 같은 **밀다**에 N두갈래 변형을 별도 전이 표본으로 비교하는 것이 더 직접적이다.
- 그 전이에 필요한 노랑 S두갈래는 보내다에서 이미 있으므로 전체 집합에는 파랑 N두갈래 1종만 추가되어 **11종**이다. 밀다의 W/N형과 무표지를 모두 보여주는 별도 비교 메뉴는 7종이다. N형 전이 2배치도 같은 다각형 검사에 통과했지만 기본 메뉴 10종에 포함하지 않았다.
- 원형=피동자, 두 갈래=모든 파랑에 적용되는 행위자라는 규칙으로 확대하지 않는다. 상태 대상은 행위자 구분과 다르다.
- 목록 제한은 선택할 외곽 수를 줄인다. 역할 이해·문맥 판단·혼동 사례를 없애지는 않는다. 모형 복사나 특정 입력 절차만을 정답으로 강제하지 않는다. 전체 목록 열기 기능도 임의로 추가하지 않는다.

검사 범위는 위 낱개 모형과 배치의 도달 가능성이다. 모든 자유 조립, 모든 방향 조합, 긴 노랑 연결, 실제 드래그·메뉴 조작, 초견 이해와 재미, 본편 전체 제작량을 검증한 결과는 아니다.
