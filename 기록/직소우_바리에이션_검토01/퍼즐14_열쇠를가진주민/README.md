# 퍼즐14 — 열쇠를 맡은 주민

2026-09-29 · 사용자 요청 “오케이 2번만들어줘”에 따른 독립 HTML 플레이 표본.

[플레이](플레이.html) · 브라우저에서 파일을 열면 실행. 포트·서버·외부 의존성 없음.

## 장면과 판단

밖에는 주민 둘, 집 안에는 관리인이 있다. 관리인이 만나려는 사람은 열쇠 보유자다. 한 주민은 나→가지다→열쇠, 다른 주민은 나→가지다→책으로 말한다. 둘 다 밖에 있으므로 위치만으로는 대상이 좁혀지지 않는다.

같은 주민 조각에서 보유 상태와 이동 행동을 분기한다. 가지다는 현재 소지품에 따른 대상 선정, 가다는 그 대상의 실제 이동이다. 클릭한 사람이나 마지막 발화자는 명령 대상 선정에 사용하지 않는다. 두 주민이 함께 듣는다.

| 입력/상황 | 반응 |
|---|---|
| 주민→가다→안 | 두 주민 모두 해당되어 머뭇거림 |
| 같은 주민에서 가지다→책 / 가다→안 | 책 주민이 관리인에게 갔다가 돌아옴. 조립 유지 |
| 같은 주민에서 가지다→열쇠 / 가다→안 | 실제 열쇠 보유자가 관리인에게 도착하여 완료 |
| 목적지 집→안 | 안과 동등 수용. 가다 출력은 집 또는 안에 연결 가능 |
| 열쇠 자체를 가다 주체로 사용 | 물건을 주민으로 치환하지 않고 잘못된 이동 주체로 응답 |
| 다른 주민의 보유 조건을 연결 | 이동 주체와 다른 조건으로 거절 |

모형/글자 분리, 비소모 재사용, 회전 없음, 노랑 사슬 최대3 유지. 노랑 대상·파랑 서술과 기존 실제 원형 돌출/홈 외곽을 사용한다. 목적지를 생략한 이동 명령은 보완을 요청한다. 본편 Unity 구현 보류 및 이전 퍼즐13 보존.

## 실행 검증

- core.test.js: 25개 통과. 표현 변형·실제 소지품 변경·주민 ID 교환·모호함·주체 혼입·세계 불변성 포함.
- Edge 실제 DOM 조작: 15개 통과. 발화, 모호한 요청, 되돌리기, 책 주민 입장/복귀, 정답 이동, 이동 중 소리 버튼, 재시작 취소, 짧은 목적지 포함. browser-results.json 참조.
- 실제 페이지 새로고침: 7개 통과. 조각/들은 말/대화/완료/위치 복원 및 휠 강조 초기화. reload-results.json 참조.
- 메인이 Edge 헤드리스 플레이·완료 화면을 직접 시각 확인. 독립 검토자가 읽기 전용으로 UI/엔진 연결 검토. 지적된 재시작 시 휠 강조 잔류 수정.
- 사용자 실제 플레이: 주민→가지다→열쇠→가다→집→안 직선형을 제출하고 오류 여부를 질문했다. 열쇠가 이동 주체가 되는 연결임을 설명하고, 같은 주민에서 보유와 이동을 분기하도록 안내한 뒤 사용자가 해결했다. 이어 “고민하는 재미가 있었어”라고 평가했다. 분기 설명 후 해결한 경험이며 무힌트 자력 해결로 기록하지 않는다.

## 파일

보기.template.html + style.css + app.js + core.js를 만들기.py로 묶어 플레이.html 생성. 모형은 연결확장08 생성기, 글꼴은 기존 Pretendard를 재사용한다. 빌드 시 shapely/fontTools가 필요하며 완성 HTML에는 설치가 필요 없다.

저장 키 grad.puzzle14.v1. 퍼즐13 저장에 접근하지 않는다. 이동 완료 때 세계 상태를 저장하며 이동 도중 새로고침하면 이전 안정 상태로 복귀한다. 테스트는 별도 test 키와 임시 파일/브라우저 프로필을 사용했다. browser.test.js/reload.test.js는 완성 HTML 끝에 삽입해 재현할 브라우저 검사 스크립트다.
