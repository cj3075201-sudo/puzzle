# A 제작자의 B 교차 UI 플레이

참가자 a. B의 소스/설계/정답/API/다른 참가자 기록은 열지 않았다. UI 브로커의 화면 텍스트·접근성 컨트롤·좌표만으로 모형/글자/인물을 클릭해 플레이했다. A 제작 중 동일 원본 직소 엔진을 충분히 알았으므로 순수 초견 C와 분리한다. 장면05→09→07 순서. 첫 완료 후 화면의 ‘이 퍼즐 다시 시작’으로만 대안을 시험했고 같은 케이스를 재open하지 않았다.

시간은 내 UI 증거 JSON 파일의 생성 시각(파일 mtime) 차이를 사용한 에이전트 벽시계 시간이다. 도구 대기·읽기·추론·보고를 포함하며 인간 플레이 예상 시간이 아니다. 첫 완료 뒤 대안은 별도 측정했다.

|---|---|---:|---:|---:|---:|---:|---|
|05 / B1 울리지 않는 이유|1 / 11 / 20|15.31초|32.28초|4|1|0|없음|
|09 / B2 안전해도 건너지 않는 사람|1 / 15 / 28|18.12초|30.87초|3|0|0|없음|
|07 / B3 열어 달라, 닫아 달라|1 / 15 / 32|10.26초|25.60초|4|0|0|없음|

## B1

정비사의 연결 설명을 들었다. 처음에는 부모 원인인 전원을 직접 시험하는 게 가장 빠르다고 판단해 전원→시험하다를 제출했다(step11). 밀봉되어 직접 볼 수 없다는 반응을 처음 받았다. 부품별 시험이 모두 가능한 듯한 기본 규칙과 이 예외 사이에서 한 번 막혔지만, 대안인 종/램프 시험은 명확했다.

종→시험하다에서 무음(step14), 램프→시험하다에서 밝음(step16)을 얻었다. 램프의 빛으로 전원 정상, 종 무음으로 종 고장을 추론해 종→고치다로 완료(step20). 이전 정적 설명 조립과 달리 내 시험 행동으로 증거를 생성하는 효용은 있다. 이 장면은 복잡한 언어 문법 없이 진료의 감별 행위로 옮기기 쉽다.

추가 우회: step22 초기화 후 정비사 대화·시험을 전부 생략하고 종→고치다만 제출해 step31 완료했다(6.05초). 원인을 이미 아는 재플레이이므로 초견에서도 직감 정답이라고 주장하지 않는다. 다만 임의 수리에도 비용이 없고 후보가 셋뿐이므로 시험의 필요성은 현재 규칙에서 강하지 않다. 첫 풀이는 의미 있었지만 모든 부품을 순차 수리하는 반복이 유리해질 가능성은 남는다.

증거: 05/002 연결 설명, 011 전원 거절, 014 종 무음, 016 램프 빛, 020 첫 완료, 022 초기화, 031 시험 생략 완료.

## B2

수리 완료된 실제 물길과 여행자의 오래된 믿음이 처음부터 분리되어 있었다. 두 인물의 설명을 들은 뒤 여행자→가다→관찰창(step15), 기사에게 수문→열다(step22), 여행자→건너다(step28) 순으로 완료했다. 시간 대부분은 이미 떠올린 세 행동을 모형/글자 클릭으로 조립하는 데 썼다. 핵심 판단에는 막힘이 없었다.

추가 시험: step30 초기화. 수문을 먼저 열어 물을 흘렸으나 벽 뒤 여행자는 못 봄(step39). 뒤늦게 관찰창에 보내도 현재 물길을 보고 기억이 바뀜(step49). 여행자를 다시 벽뒤로 보낸 뒤(step51) 건너라고 해도 step55 성공했다(대안 15.44초). 고정 행동 순서를 검사하는 퍼즐이 아니라 ‘봤다는 기억’이 남는 상태를 실제로 사용한다. 이 차이는 의미 있다.

이 표본에서의 추천: 난도 높은 퍼즐보다는 소통 대상의 지식/경험을 다루는 초반 장면으로 적합하다. 옛 소통12의 청자가 무엇을 볼 수 있는지 생각하는 기능에서, 직접 보는 사건과 기억 유지로 확장했다. 제목/설명이 이미 핵심 문제를 공개하므로 낯선 대상의 관점을 발견하는 놀라움은 약했다.

증거: 09/002 기사 정보, 015 창 이동, 022 관찰 기억 변경, 028 첫 완료, 039 먼저 연 뒤 미관찰, 049 나중에 관찰 성공, 051 벽뒤 복귀·기억 유지, 055 대안 완료.

## B3

첫 화면의 마른 화단·물고기 상태와 격자/천 어휘를 보고 격자로 물만 보내는 해법을 먼저 예상했다. 이를 확인하려고 정원사와 돌보미에게 각각 질문→사람→원하다를 조립했다(step15,19). 정원사는 물만, 돌보미는 물고기 잔류를 원한다. 장치 클릭(step20)으로 격자는 물을 통과시키며 천은 둘 다 막는다는 사실을 확인하고 격자 끼우기(step27), 수문 열기(step32)로 완료했다.

추가 우회: step34 초기화 후 두 사람에게 질문하지 않고 장치만 선택해 격자 끼우기→수문 열기로 step48 완료(2.85초). 원래도 첫 화면에서 해당 해법을 예상할 정보가 있었고 대화가 완료 조건은 아니다. 대화 의도를 묻는 연출은 의미 있으나 이번 표본은 ‘물리 필터를 맞추면 갈등이 해소되는 퍼즐’로도 완전히 해결된다. 질문 조각이 새로운 논리 난도를 만들었다고 평가하기 어렵다.

직전 파랑 질문 노드를 삭제하고 남은 노랑 주민→파랑 원하다의 글자를 격자→끼우다로 바꿔 재사용했다. 새 노랑 시작에 남아 있던 왼쪽 홈이 사용되지 않아도 유효한 기존 규칙을 그대로 활용했다. 기하 실패는 없었다.

증거: 07/001 질문 전 최초 정보, 015 정원사 목적, 019 돌보미 목적, 020 격자/천 조건, 032 첫 완료, 034 초기화, 048 질문 생략 완료.

## 실질 가치 판단

B1은 ‘증거를 어떻게 얻을지’ 선택을 추가하므로 세 안 중 퍼즐화의 확장 가능성이 가장 높다. 현재 셋 중 하나·무료 수리 표본은 작아 탐구 우회가 쉽다. B2는 사고 깊이 증가보다 타인의 경험을 바꿔 설득한다는 언어 어드벤처의 경험 가치가 크고, 순서와 기억을 실제 상태로 계산한 점이 확인됐다. B3는 갈등을 목적 수준에서 다시 읽는 장면으로는 쓸 수 있지만 격자 기능과 목표가 모두 보이면 질문 기능의 추가 효용은 주로 맥락 설명이다. 셋 모두 본편 후반 깊이를 입증한 결과는 아니며, 짧은 초반 변주로 구별하면 사용할 의미가 있다.
